Веб-приложение ASP.Net Core
Применялся паттерн MVC

Функциональность:
- Пользователи библиотеки - это клиенты и администраторы;
- доступ к содержимому медиатеки открыт только для зарегистрированых пользователей;
- пользователь может зарегистритьваться;
- пользователь может выполнить вход в систему;
- аудиофайл из медиатеки можно скачать или перейти к подробной информации;
- можно использовать поиск по каталогу;
- можно выбрать категорию аудио;
- в режиме администратора доступны действия по добавлению, изменению и удалению файлов в медиатеке;
- пользователь имеет личный кабенет, где может изменить информацию о себе.

Для работы подключить базу, она прописана в program.cs - нужно проверить сервер, закоментить посев данных, создать миграцию и обновить базу, вернуть посев
